台股分析儀表板 - 部署教學

這份教學是要把儀表板放到網路上，讓別人不用裝 Python、不用下載程式，只要點一個網址就能用。 用的是 Streamlit Community Cloud，完全免費，但有兩個前提要先知道：

  • 需要一個 GitHub 帳號（也是免費的），用來放程式碼
  • 部署完成後的網址是公開的，任何拿到連結的人都能打開使用，目前沒有加密碼限制

我已經把專案準備好了（整理成 GitHub 需要的格式），接下來的步驟需要你自己的帳號操作，我沒辦法代替你登入或建立帳號。以下每一步都會寫清楚要點哪裡。

第一步：申請 GitHub 帳號（如果還沒有）

  1. 打開瀏覽器，到 github.com
  2. 點右上角「Sign up」，依指示輸入 Email、設密碼、取一個帳號名稱
  3. 會需要驗證 Email，收信點一下驗證連結就完成了

如果已經有帳號，這步跳過，直接登入即可。

第二步：在 GitHub 建立一個新的 Repository（程式碼倉庫）

  1. 登入後，點右上角「+」→「New repository」
  2. Repository name 填 tw-stock-dashboard（或你喜歡的名字，英文或數字比較不會出問題）
  3. 選擇 Public（公開）——Streamlit 免費方案要用公開的倉庫
  4. 下面「Add a README file」不要勾（我們自己的專案裡已經有了）
  5. 按「Create repository」

第三步：把專案資料夾上傳到 GitHub

這裡有兩種做法，選一種就好：

方法 A：直接拖拉上傳（不用打指令，適合大多數人）

  1. 在剛建立好的 repository 頁面，點「uploading an existing file」（或「Add file」→「Upload files」）
  2. 打開電腦裡的專案資料夾「台股分析儀表板」，把裡面所有檔案和資料夾（app.py、config.py、data、analysis、explain、ui、requirements.txt、.streamlit 等）全部選取後拖進網頁——不要整個「台股分析儀表板」資料夾本身拖進去，是拖「裡面的東西」
  3. 不要上傳：venv 資料夾（很大且不需要）、app.py.bak、holdings.json（如果還在的話）。我已經寫了一份 .gitignore 清單提醒這件事，但網頁拖拉上傳不會自動套用這份清單，需要你自己不要選到這些
  4. 下方輸入一句提交訊息（例如「初次上傳」），按「Commit changes」

方法 B：用終端機的 git 指令（如果你不排斥再打開一次終端機）

我已經在專案資料夾裡準備好 git 版本控管了（.gitignore 已經排除不該上傳的檔案）。打開終端機，切到專案資料夾，貼上以下指令（把 你的帳號 換成你的 GitHub 帳號名稱、你的倉庫名稱 換成第二步取的名字）：

cd "專案資料夾的完整路徑/台股分析儀表板"
git remote add origin https://github.com/你的帳號/你的倉庫名稱.git
git push -u origin main

第一次 push 時系統可能會跳出瀏覽器要你用 GitHub 帳號登入授權，照著做就好。

第四步：到 Streamlit Community Cloud 部署

  1. 打開 share.streamlit.io
  2. 點「Sign in」，選擇用 GitHub 帳號登入（會跳出 GitHub 授權畫面，同意即可）
  3. 點「Create app」（或「New app」）
  4. Repository 選你剛剛建立的那個（例如 你的帳號/tw-stock-dashboard）
  5. Branch 選 main
  6. Main file path 填 app.py
  7. 按「Deploy」，等個一兩分鐘讓它安裝套件、啟動程式

完成後會拿到一個網址，格式類似 https://你的帳號-tw-stock-dashboard-xxxx.streamlit.app，這就是可以分享給別人的連結。

之後怎麼更新

之後如果我幫你改了程式碼，你只要重複「第三步」把新的檔案再上傳一次到同一個 GitHub repository（覆蓋舊檔案），Streamlit Community Cloud 會自動偵測到變動，幾十秒內自動重新部署，不用重新跑一次第四步。

常見問題

部署後打不開 / 出現紅字錯誤？ 通常是 requirements.txt 裡某個套件版本在雲端裝不起來，把錯誤畫面完整截圖給我，我可以幫忙看。

可以設密碼、不要公開嗎？ Streamlit Community Cloud 的免費方案沒有內建密碼保護，但可以自己在程式裡加一段簡單的密碼輸入畫面（沒輸對密碼就不顯示內容）。如果你需要這個，跟我說，我可以幫你加上去。

會一直免費嗎？ Streamlit Community Cloud 的公開 App 目前是免費的，但如果长期没人使用，平台可能会把 App 暫停（休眠），只要有人重新打開網址，它會自動醒過來，等個幾十秒就好，不用擔心資料遺失。

雲端上的資料會跟我本機的一樣嗎？ 股價、新聞、籌碼資料都是即時向 Yahoo Finance／證交所／Google 新聞查詢的，跟本機執行時抓到的是同一批資料來源，只是快取只在該次連線期間有效，重新整理網頁或伺服器重啟後會重新抓一次。

部署完成後，記得把網址填回 README.md 裡「線上使用」那一段，方便之後查找。
