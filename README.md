# 台股分析儀表板

用 Streamlit 打造的台股互動式分析工具，輸入股票代號或中文名稱，馬上看到目前價格、一句話結論（紅黃綠燈）、K 線走勢、風險等級與參考價位、技術指標（RSI、KD）、三大法人買賣超、近期新聞，以及獲利與股利概況。

介面針對長輩／平板使用者設計：大按鈕、大字體、不用側邊欄，資訊分層呈現，並在特定技術面事件發生時才顯示白話說明。純唯讀查詢工具，不保存任何使用者資料、不寫入任何本機檔案。

## 線上使用

部署好之後，把 Streamlit Community Cloud 給的網址貼在這裡：

`（部署完成後填入網址）`

## 本機執行

雙擊 `啟動儀表板.command`（Mac）或 `啟動儀表板_Windows.bat`（Windows），第一次執行會自動安裝套件。詳細操作說明見 `操作說明.html`。

## 專案結構

```
app.py                  # 頁面路由與版面組裝
config.py                # 色票、快取時間、字級常數
styles.py                 # 自訂 CSS 與共用 HTML 元件
data/                      # 資料抓取（股價、代號對照表、新聞、三大法人、基本面）
analysis/                  # 技術指標、風險與結論計算、動態事件偵測
explain/                    # 所有白話說明文字的唯一來源
ui/                          # 圖表與卡片元件、版面元件
```

## 資料來源

股價、三大法人買賣超、股票代號對照表：台灣證券交易所公開資料（目前股價查詢僅支援上市個股，上櫃個股暫無歷史資料來源）。獲利與股利：Yahoo Finance（yfinance），台股覆蓋率不一定完整。新聞：Google 新聞 RSS。

資料僅供參考，不構成投資建議。
